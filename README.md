# 🚚 Animated "Book a Demo" Button

This is a fun, interactive UI component featuring a truck-themed **"Book a Demo"** button built using **HTML**, **CSS**, and **jQuery**. When clicked, the button animates with a moving truck, a package drop-off, and a success checkmark — providing a unique, visually engaging experience.

---

## 🔧 Features

- ✅ Smooth, engaging animations
- 🚛 Truck animation with SVG and CSS transitions
- 📦 Package drop effect
- ✔️ Success state with animated checkmark
- 🎨 Fully responsive and styled using CSS variables

---

## 📁 Project Structure

📦 project-root
├── index.html # HTML structure
├── style.css # Styling and animations
└── script.js # Click interaction logic using jQuery
